Security groups: internet to load balancer on port 80 only. Load balancer to instances on 8080 and 3000 only. Instances to database on 5432 only. No port 22: shell access is through SSM Session Manager.
Instance start: each instance reads the image tag and compose file from SSM, gets the database password from Secrets Manager, pulls the images from ECR through the NAT gateway and starts both containers.
Failure tolerance: if an instance or a zone fails, the load balancer sends traffic to the healthy zone and the Auto Scaling group launches a replacement.
